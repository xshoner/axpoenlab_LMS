# 대시보드 성능 및 강좌 기본 화면 (2026-09-28)

## 강좌 화면

- 슈퍼관리자: 마스터 강좌가 기본 화면이며 내 강좌 탭과 내 강좌로 복사 버튼은 표시하지 않는다.
- 일반 관리자: 내 강좌가 기본 화면이다. 마스터 읽기·복사와 자신의 기수별 강좌 관리 기능은 유지한다.
- 슈퍼관리자가 일반 관리자의 화면을 확인하면 해당 관리자의 내 강좌 화면을 기본으로 보여 준다.
- 과거 슈퍼관리자 개인 그룹이 있으면 마스터 라이브러리에 포함한다. 원래 그룹·강좌 데이터는 이동하거나
  삭제하지 않는다. 종전 `/courses/mine/:id` 링크도 슈퍼관리자에게 마스터 상세로 표시한다.

## 원인과 변경

- 방문 집계에서 각 방문 행마다 역할·소유권을 조회했다. 현재 요청의 역할과 소유자를 한 번 평가하도록 변경했다.
- 관리자 기본 현황의 8개 HTTP 요청을 RLS가 적용되는 조회 RPC 하나로 묶었다.
  기수 목록 로딩을 계기로 같은 현황을 다시 요청하지 않는다. 선택 기수의 설문·퀴즈 응답과 문의는 병렬 조회한다.
- 학생 대시보드의 최대 11개 요청과 최대 4단계의 순차 대기를 하나의 RLS 조회 RPC로 바꿨다.
- 세션 복원과 로그인 이벤트가 겹치면 진행 중인 프로필 요청을 공유한다. 프로필·기수 정보를 함께
  반영해 초기 대시보드 중복 조회를 없앤다. 로그아웃 뒤 도착한 응답은 버린다.

## 운영 DB 측정

운영 데이터에 변경안을 트랜잭션 안에서 적용하고 조회한 뒤 롤백하여 비교했다.
다음은 `EXPLAIN ANALYZE` 단일 실행 시간으로, HTTP·브라우저 시간을 포함하지 않으며 부하와 캐시에 따라 달라진다.

| 조회 | 기존 | 개선안 |
| --- | ---: | ---: |
| 일반 관리자 방문 집계 | 1,885ms | 2.1ms |
| 일반 관리자 방문 추이 | 1,393ms | 2.4ms |
| 슈퍼관리자 방문 집계 | 354ms | 1.5ms |
| 슈퍼관리자 방문 추이 | 177ms | 1.6ms |
| 학생 로그인 시 방문 집계 | 488ms | 1.4ms |

새 기본 대시보드 RPC 전체 처리 시간은 슈퍼관리자 약 28ms, 일반 관리자 약 151ms,
학생 약 115ms였다. 관리자 선택 기수 상세와 북마크 등 별도 위젯은 이 시간에 포함되지 않는다.
재측정 SQL은 `supabase/tests/dashboard_performance.sql`이다.

## 검증

- 전체 마이그레이션·기존 데이터 보존·권한 격리 회귀 테스트.
- 신규 대시보드 집계와 기존 직접 조회의 건수·데이터 비교, 관리자 화면 확인 범위 및 비공개 강좌 차단.
- 실제 React 컴포넌트 렌더링으로 역할별 기본 탭, 슈퍼관리자 내 강좌 탭 제거, 기존 링크 확인.
- 실제 인증 Provider를 제어된 비동기 어댑터로 실행하여 요청 중복 방지·기수 동시 반영·로그아웃 응답 무시 확인.
- 기존 회원·강좌·기수 데이터는 변경하지 않는다. 신규 RPC는 SECURITY INVOKER이며 현재 RLS를 그대로 적용한다.
- 운영 마이그레이션 `20260928030000` 적용 시 같은 트랜잭션에서 45개 테이블, 3,185개 행의
  모든 기존 컬럼 값과 건수를 해시로 비교하여 보존을 확인했다. 운영 역할·대시보드 범위 테스트도 통과했다.

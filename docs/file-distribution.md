# 학생 쪽지·파일 배포

관리자 상단 **쪽지/파일**(화면공유 오른쪽) → 기수 선택 → 제목·쪽지 내용·첨부파일 선택 → 기수 전체 또는 학생 선택 → 보내기.

- 한 번에 최대 10개. 파일당 용량과 확장자는 LMS 시스템 설정을 적용하며 저장소 최대 용량은 50MB이다.
- 첨부 영역에 여러 파일을 끌어다 놓거나 클릭·키보드로 선택해 추가한다. 같은 이름·용량·수정 시각의 중복 파일은 제외하며, 전송 전 목록에서 개별 제거할 수 있다. 10개를 넘기면 기존 선택을 유지하고 안내한다. 전송 중에는 첨부 변경을 차단한다.
- 전송 시점의 활성 학생을 대상으로 지정한다. 나중에 가입한 학생에게 과거 전송이 자동 배포되지 않는다.
- 쪽지만 보내거나 파일만 보낼 수 있으며, 쪽지와 첨부파일을 함께 보낼 수도 있다. 쪽지 내용은 기존 리치 편집기를 사용한다.
- 학생은 실시간 팝업과 상단 **쪽지/파일**의 받은 목록에서 확인·다운로드한다. 기존 쪽지와 파일 배포도 같은 목록에 유지한다. 미접속자는 다음 로그인 때 확인한다.
- 퀴즈·설문 집중 화면에서도 같은 메뉴와 실시간 수신이 동작한다.
- 학생이 받은 항목을 삭제하면 자신의 목록에서만 숨겨진다. 관리자 수신 기록과 다른 학생의 목록은 유지된다.
- 수신 현황: 알림 수신(인증된 목록 조회), 확인(자료 팝업/상세 화면 표시), 파일별 다운로드 요청(다운로드 버튼 클릭 후 서명 URL 발급 성공).
- 다운로드 요청은 실제 PC 저장 완료 또는 파일 열람을 보증하지 않는다.
- 관리자 권한은 담당 기수, 슈퍼관리자는 전체 기수에 적용한다. 관리자 확인 모드에서는 변경이 차단된다.
- 비활성 계정이나 해당 기수에서 탈퇴한 학생은 새로운 다운로드 링크를 발급받을 수 없다. 기존 서명 URL은 5분 후 만료된다.
- 파일은 비공개 `student-deliveries` 버킷에 한 번 저장한다. 공개 URL 및 Daily 연결을 사용하지 않는다.
- 전송은 서버 트랜잭션으로 처리한다. 실패한 전송은 동일 ID로 재시도하여 중복 배포를 방지한다.
- 초안 생성·업로드·전송 확정의 일시적인 504/네트워크 오류는 최대 3회 시도한다. 초안은 브라우저에서 만든 동일 ID를 사용한다. 업로드 응답 유실 후 중복 파일 응답은 실제 저장된 크기를 확인하고 이어간다. 업로드 요청은 120초, 초안·전송 확정 요청은 15초로 제한하며 오류에 실패 단계를 표시한다.
- 미전송 파일은 창 닫기 시 정리한다. 새로고침 등으로 남은 임시 업로드는 전송 이력의 **임시 파일 정리**에서 제거한다. 전송된 파일은 덮어쓰거나 임시 정리로 삭제할 수 없다.
- **전송 이력 · 수신 현황**은 기본적으로 접혀 있다. 이력을 펼치고 개별 전송 항목을 펼치면 첨부파일 관리·수신 요약·학생별 현황을 한 화면에서 확인한다. 이력 또는 항목을 접으면 수신 현황 자동 조회도 중단한다. 모바일에서는 학생별 상태를 카드 형태로 표시한다.
- 슈퍼관리자는 전송 이력의 개별 항목을 펼쳐 **파일 삭제 → 파일 영구 삭제**에서 개별 첨부파일을 제거한다. 서버가 활성 슈퍼관리자 권한을 확인하고 Storage API로 실제 파일을 삭제한 후 삭제 시각·관리자 감사 기록을 남긴다. 일반 관리자·학생·관리자 확인 모드는 삭제할 수 없다.
- 삭제는 모든 수신 학생에게 적용하며 파일 저장 용량을 회수한다. 쪽지 본문·파일명·수신/확인/다운로드 요청 이력은 남고 학생 화면에서는 삭제된 파일의 다운로드 버튼이 사라진다. 삭제 도중 실패하면 성공으로 표시하지 않으며 같은 파일로 재시도할 수 있다. 이미 PC에 내려받은 사본까지 삭제하지 않는다.
- 학생 목록·수신 현황은 전체 행을 페이지 단위로 조회하며, 전송 이력·받은 파일 목록은 20개씩 표시한다.
- 실시간 연결을 놓치면 30초 간격과 탭 복귀 시 재조회한다. 수신 현황 창을 열었을 때만 5초 간격으로 갱신한다.
- 받은 목록의 반복 조회는 제목·시각·첨부 개수만 가져오며 본문과 다운로드 정보는 열 때 조회한다. 파일은 브라우저가 원본 바이트를 직접 내려받고 Storage의 다운로드 헤더로 한글 파일명을 유지한다.
- 전송 성공 후 이력 조회에 실패하더라도 전송 완료 상태를 유지하고 이력 조회 오류만 표시한다. 중복 전송을 유도하는 재시도 안내를 표시하지 않는다.
- 이전 쪽지 이력의 수정·재발송 기능은 통합 전송 화면의 접힌 이전 이력에서 사용할 수 있다.

학생 상단 접속 수는 전체 기수의 활성 접속 학생(90초 내 heartbeat), 오늘·누적 방문은 전체 LMS 방문 기록 기준이다. 오늘은 한국 시간으로 집계하고 누적은 날짜별 방문 기록 합계다. 전체 숫자만 노출하며 관리자별 원본 데이터 접근 권한은 그대로 유지한다. 화면공유 월 사용량은 상단 버튼에서 제외하며 운영 현황에서 조회한다.

접속·방문 표시는 하나의 통계 응답을 공유한다. 정적 빌드 파일(`/assets/`)은 내용별 파일명으로 1년 캐시하며 HTML은 기존 갱신 방식으로 유지한다. 백업은 DB 페이지와 파일 하나씩 압축·암호화하고 복호화 결과의 SHA-256을 비교한다. 기존 `AXLMSB1` 복원 형식과 원본 파일 품질을 유지한다.

검증: `npm run test:tenancy`, `npm run test:screen-share`, `npm run test:stability`, 빌드 후 `node scripts/test-browser.mjs`.
